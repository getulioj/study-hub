Study Hub — Bootcamp I

Projeto acadêmico desenvolvido no curso de Ciência da Computação do UniCEUB.

Sobre o projeto

O Study Hub é um espaço digital criado para organizar conteúdos acadêmicos, acompanhar minha evolução durante a graduação e reunir projetos de tecnologia.

Objetivos

Organizar as disciplinas do semestre.

Registrar atividades, anotações e projetos.

Desenvolver conhecimentos em desenvolvimento web.

Aprender boas práticas de versionamento com Git e GitHub.

Construir um portfólio acadêmico e profissional.

Tecnologias utilizadas

HTML5

CSS3

Git
